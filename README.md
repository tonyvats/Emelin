# Сергей Емелин — визитка

Одна страница ведущего: пять форматов и прямой контакт. Без прайса, отзывов и рассказа «обо мне». Тексты написаны от первого лица, от имени Сергея.

Факты на странице взяты из открытой группы [vk.ru/sergeyemelinofficial](https://vk.ru/sergeyemelinofficial): имя, телефон, география. Фото лежат в `public/photos`, ужатые до 2000 px по длинной стороне: портрет для первого экрана, шесть кадров для ленты и пять отдельных для списка форматов. Порядок и привязка к форматам задаются в `lib/site.ts`.

## Запуск на своём компьютере

Нужен Node.js 20 или новее. Проверка: `node -v`.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере на этом же компьютере.

Форма заявки ничего не отправляет на сервер. Она собирает текст, чтобы его скопировать во ВК или продиктовать по телефону.
