# Сергей Емелин — визитка

Одна страница ведущего: пять форматов и прямой контакт. Без прайса, отзывов и рассказа «обо мне».

Факты на странице взяты из открытой группы [vk.ru/sergeyemelinofficial](https://vk.ru/sergeyemelinofficial): имя, телефон, география. Свадебные фото гостей на сайт не перенесены.

## Запуск

```bash
npm install
npm run dev -- -p 47281 -H 0.0.0.0
```

Откройте [http://127.0.0.1:47281](http://127.0.0.1:47281).

Форма заявки ничего не отправляет на сервер. Она собирает текст, чтобы его скопировать во ВК или продиктовать по телефону.
